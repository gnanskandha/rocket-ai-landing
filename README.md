# 🚀 Interactive Rocket AI: Reward Shaping & Hacking

A Reinforcement Learning project demonstrating how an AI learns to land a lunar module, how it learns to "cheat" when given flawed incentives (Reward Hacking), and how to fix it. Includes an interactive Streamlit web dashboard.

## 🎮 Interactive Dashboard
This project includes a real-time Streamlit web app (`interactive_app.py`) where you can:
- Change the landscape terrain on the fly.
- Move the landing pad left or right.
- Control the simulation speed.
- Watch the AI adapt and land in real-time!

## 🛠️ How to Run Locally
1. Install dependencies: `pip install -r requirements.txt`
2. Train the AI: `python 06_train_corrected.py`
3. Launch the Web App: `streamlit run interactive_app.py`
